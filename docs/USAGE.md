# Использование · How to use

[Русский](#русский) · [English](#english) · [← README](../README.md)

## Русский

- Откройте **Подключение** у нужного джойстика и выберите M30.
- Нажимайте кнопки геймпада и смотрите их отображение на схеме.
- Если Android не позволяет подключение или переименование внутри приложения, используйте предложенные системные настройки или метку приложения.
- Подключение прокручивает страницу к Bluetooth; крестик возвращает к прежнему месту.

В меню M30 нажмите **Забыть устройство**. На поддерживаемом Android 16 и новее приложение попросит Android удалить пару. Если потребуется, подтвердите доступ к выбранному M30 в системном окне. Если прямое удаление недоступно, откройте предложенные настройки Bluetooth. Приложение уберёт запись, метку, номер и привязку только после подтверждённого удаления пары. При отмене пара и метка сохраняются; подключить M30 можно из **Ранее подключённых**, без нового поиска. Если пары уже нет, этот же пункт очищает оставшуюся запись. **Отключить** работает внутри приложения на поддерживаемом Android; иначе используется системный Bluetooth.

Режим геймпада переключается на самом M30. Подписи на схеме помогают проверить кнопки и не меняют управление в играх.

Установка версии 1.62: поверх 1.61 без удаления приложения и данных. Для Obtainium включите **Предварительные выпуски**.

## English

- Open **Connection** for the controller slot you want, then select the M30.
- Press buttons on the controller and watch the diagram.
- If Android cannot connect or rename the controller in the app, use the offered system settings or an app-only label.
- Connection scrolls to Bluetooth; the close button restores the previous position.

In the M30 menu choose **Forget device**. On supported Android 16 and newer devices, the app requests removal from Android. If prompted, approve access to the selected M30 in the system dialog. If direct removal is unavailable, use the offered Bluetooth settings. The app clears the entry, label, number and slot link only after removal is confirmed. Cancelling keeps the pair and label; reconnect from **Previously connected** without searching again. If no pair exists, the same action clears the remaining app entry. **Disconnect** works in the app on supported Android versions; otherwise it uses system Bluetooth.

Switch the controller's mode on the M30 itself. Diagram labels help you test buttons; they do not remap game controls.

Installing version 1.62: update over 1.61 without uninstalling or clearing data. Enable **Pre-releases** in Obtainium.
