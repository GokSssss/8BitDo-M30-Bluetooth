# Использование · How to use

[Русский](#русский) · [English](#english) · [← README](../README.md)

## Русский

- Откройте **Подключение** у нужного джойстика и выберите M30.
- Нажимайте кнопки геймпада и смотрите их отображение на схеме.
- Если Android не позволяет подключение или переименование внутри приложения, используйте предложенные системные настройки или метку приложения.
- Подключение прокручивает страницу к Bluetooth; крестик возвращает к прежнему месту.

В меню M30 нажмите **Забыть устройство**. Если пара есть, удалите её в открывшихся настройках Android. Приложение уберёт запись и метку после подтверждённого удаления. При отмене пара и метка сохраняются; подключить M30 можно из **Ранее подключённых**, без нового поиска. Если пары уже нет, этот же пункт очищает оставшуюся запись. **Отключить** работает внутри приложения на поддерживаемом Android; иначе используется системный Bluetooth.

Режим геймпада переключается на самом M30. Подписи на схеме помогают проверить кнопки и не меняют управление в играх.

Установка версии 1.61: поверх 1.60 без удаления приложения и данных. Для Obtainium включите **Предварительные выпуски**.

## English

- Open **Connection** for the controller slot you want, then select the M30.
- Press buttons on the controller and watch the diagram.
- If Android cannot connect or rename the controller in the app, use the offered system settings or an app-only label.
- Connection scrolls to Bluetooth; the close button restores the previous position.

In the M30 menu choose **Forget device**. If paired, remove it in Android settings. The app clears its entry and label only after removal is confirmed. Cancelling keeps the pair and label; reconnect from **Previously connected** without searching again. If no pair exists, the same action clears the remaining app entry. **Disconnect** works in the app on supported Android versions; otherwise it uses system Bluetooth.

Switch the controller's mode on the M30 itself. Diagram labels help you test buttons; they do not remap game controls.

Installing version 1.61: update over 1.60 without uninstalling or clearing data. Enable **Pre-releases** in Obtainium.
