M30 Companion1.38 — установка и проверка
Установите M30-Companion-1.38.apk поверх предыдущей версии, не удаляя приложение: сохранятся настройки и привязки. Package app.m30.companion, Android8+/TV, прежняя подпись. При необходимости Android разрешит установку из выбранного источника.
Пульт: на вкладках Left/Right переключает страницы, Up/Down выходит к действиям. В остальных областях стрелки двигают белую рамку. Слева от макета доступны Bluetooth/заряд/Choose; вправо — макет, вниз — панель или вкладки. OK открывает выбранное действие, Back закрывает окно/панель.
Bluetooth: нажмите иконку в шапке — панель в поле2. Слева «Найти устройство» запускает явный поиск (во время поиска — остановка), «Обновить сохранённые» перечитывает пары, «Системные настройки». Справа «Ранее сопряжённые» и «Найденные устройства». Включите нужный режим M30 и удерживайте PAIR2сек; результаты появляются сразу. Если адрес уже сохранён, строка обновится и останется доступной. Одинаковые имена различаются суффиксами адресов.
Новое устройство: выберите строку → Сопрячь → подтвердите Android при необходимости. Сохранённое: строка → Подключить в настройках → выберите его в Android. Для новой пары того же адреса удалите старую запись в системных настройках, включите PAIR и повторите поиск. Приложение не обходит системное управление Bluetooth HID. Нажатие геймпада в тесте подтверждает доступный ввод; одна сохранённая пара этого не доказывает.
В меню строки «Подписать режим» задаёт вашу отметку Android/Windows/macOS/Switch. Она хранится по полному адресу. Приложение не может автоматически отличить режимы по одному имени M30; без отметки показано «Режим не указан».
Полный экран Bluetooth остаётся в Дополнительно. Поиск Classic, только при действии пользователя и пока экран активен. Разрешения Bluetooth/геолокация Android8–11 запрашиваются системой при необходимости.
На TV проверить видимость рамки на всех цветах, достижимость левой колонки и отсутствие неожиданных страниц; затем поиск M30/повторный выбор пары. Здесь пройдены20core/sборка/lint, экранные тесты только скомпилированы; физическийTV/радио не проверены.
