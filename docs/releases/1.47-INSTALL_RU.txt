Установка1.47: поверх текущего приложения без удаления, Android8+/TV, прежняя подпись.
Для системного имени и точной строки: Bluetooth→сохранённое устройство→«Это Джойстик1/2». Выберите слот, где откликаются кнопки именно этогоM30. Делается один раз на Bluetooth-адрес и источник/режим; повторное подключение того же источника сохраняет связь. Ошибку исправьте «Убрать привязку» или выберите правильный слот/устройство заново. Смена режима/descriptor может потребовать новой связи.
Бирюзовый connected означает вашу связь с активным назначенным InputDevice; зелёное совпадение — только обнаружение пары в поиске. Без связи нет угадывания по одинаковому имени: вtabs остаётся имя источникаAndroid. Длинное имя сокращается в маленькой вкладке, полное доступно вBluetooth/описании доступности. Подсказка переименования под двумя колонками, перенос на узком экране допустим.
Проверьте TV: обе вкладки/имена, переименование черезAndroid, неверная/правильная привязка, disconnect/reconnect, два одинаковыхM30, переключение режима, focus и ширину подсказки.21 host suites/build/lint PASS; физические TV/phone здесь не проверены.
