M30 Companion 1.33

Установите M30-Companion-1.33.apk поверх текущей версии без удаления. Прошивку M30 повторять не нужно.

Под крестовиной на основном рисунке теперь указан вариант по её сигналам: D-PAD, ЛЕВЫЙ СТИК, ПРАВЫЙ СТИК. Пока направления не нажимались — НЕ ОПРЕДЕЛЕНО. Если Android выдаёт смешанные сигналы — НЕОДНОЗНАЧНО. Это предположение по вводу, не чтение внутренней настройки.

Нажмите крестовину или подпись на рисунке — откроется окно сочетаний:
SELECT + ↑ — D-pad
SELECT + ← — левый стик
SELECT + → — правый стик
Удерживать на физическом M30 5 секунд, до красного мигания LED. Затем отпустить кнопки и нажать направление для повторной проверки. Окно обновляет статус во время проверки; экранные пункты сами не переключают M30.

Дополнительно → Диагностика теперь открывает отдельное окно поверх экрана: своя прокрутка, живые события, устройства и «Поделиться отчётом». Закрывается кнопкой «Закрыть» или системным «Назад»; основной экран не удлиняется.

Страницы Джойстик 1/2 сохраняют Дополнительно и Прошивку; третья вкладка остаётся общим тестом клавиш без рисунка джойстика. Привязки и механизм официального обновления сохранены. В Windows / X-input пользователь подтвердил отображение батареи.

17 core-наборов, сборка/lint и подпись проверены; instrumentation скомпилирована. На физическом телефоне новые окна и определение крестовины здесь не проверялись.
