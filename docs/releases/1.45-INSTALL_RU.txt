M30 Companion1.45 — установка и проверка
Установите поверх текущей версии без удаления. Android8+/TV, package app.m30.companion, прежняя подпись.
При открытии джойстиков в landscape показывается верх страницы с Gamepad1/2 на одной высоте; положение восстанавливается после layout/автофокуса. Шапка остаётся частью общей ручной прокрутки. В portrait прежняя схема. Первый выбранный джойстик — серый фон с жёлтыми текстом/рамкой.
Bluetooth: «Ранее подключённые (N)» — число уникальных сохранённых геймпадов в этом списке; найденное совпадение второй раз не учитывается. У saved-колонки слева незатухающий индикатор позиции, видимый при переполнении. Одна кнопка «Старт поиска» после успешного начала меняется на «Стоп», повторное нажатие останавливает собственный поиск. По завершении/ошибке/уходе возвращается «Старт поиска»; разрешения/ограничение времени прежние.
Проверьте TV: переключение Gamepad1↔2 после прокрутки/с пульта без потери верхней подписи; рамка tab1, правильное N после добавления/забывания пары; длинный saved-список и ползунок; Start/Stop и удержание фокуса.20 host-наборов/сборка/lint прошли, UI-проверки только скомпилированы, реальные TV/phone здесь не проверены.
