ИЗМЕНЕНИЯ
• «Опции» сразу содержит все девять пунктов прежнего «Дополнительно» и «Прошивка · обновление USB». Промежуточное подменю убрано; проверка USB и процедура обновления сохранены.
• Подпись D-pad / Левый стик / Правый стик под крестовиной открывает короткую инструкцию. Добавлены контурный значок i и увеличенная область нажатия.
• На включённом M30: SELECT + ↑ — D-pad, SELECT + ← — левый стик, SELECT + → — правый стик. Держать одновременно 5 секунд, до короткого красного мигания ВЕРХНЕГО индикатора РЯДОМ С PAIR, затем отпустить. Нажмите направление для проверки. Режим Android / Windows при этом не меняется.
• Вместо «После сочетаний кнопок» действия разделены по состоянию M30: режимы и загрузчик — с выключенного; PAIR и крестовина — на включённом; SELECT + ↓ для обмена A/B и X/Y — на включённом в Switch, 5 секунд. Верхний красный индикатор отделён от четырёх нижних огоньков режима и связи.
