M30 Companion1.44 — установка и проверка
Установите поверх текущего приложения, не удаляя его. Android8+/TV, package app.m30.companion, прежняя подпись.
Под заголовком «Ранее подключённые» — совет переименовать одинаковые джойстики. Обычное и долгое нажатие на устройство открывает одно меню. Для сохранённой пары: Подключить, Переименовать, Отключить, Забыть устройство. Эти пункты открывают системные настройки Bluetooth с подсказкой. Выберите там указанное устройство и выполните нужное действие; приложение не нажимает системные кнопки автоматически. При возврате обновляются список пар и системное имя. Новое устройство сопрягается через пункт «Сопрячь».
С пульта сначала перемещается фокус между кнопками. При упоре в горизонтальную границу повторное нажатие соответствующей стрелки переводит на соседнюю страницу, из любой области основного экрана. Во вкладках переход прежний. Удержание не должно перепрыгивать несколько страниц, на внешних краях первой/последней страницы перехода по кругу нет. Физический M30 остаётся в тесте кнопок.
Проверьте на TV/телефоне обычное/долгое OK/тап,4пункта меню, системное переименование/отключение/забывание с возвратом, переходы от шапки/Bluetooth/профилей/нижних кнопок, работу M30 без перелистывания.20 host-наборов/сборка/lint прошли, instrumentation только скомпилирована; физическая проверка здесь не выполнена.
