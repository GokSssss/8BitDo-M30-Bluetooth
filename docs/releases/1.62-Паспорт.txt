M30 Companion 1.62 / versionCode63 — 16.11.2026
Проверочный выпуск (Pre-release).

Один пункт «Забыть устройство» пробует удалить системную пару из приложения на Android16+ при поддержке companion device setup. При необходимости Android запрашивает доступ к конкретному M30. Если API/служба недоступны или система отказала, предлагаются настройки Bluetooth. Без root, Accessibility и скрытого removeBond.
Метка, номер, legacy mode, MAC→source и собственная companion association этого адреса очищаются только после BOND_NONE/свежего успешного снимка без пары. true от API — только начало запроса. Foreground ожидание30s; при timeout данные сохраняются и предлагается Android Settings. Отмена/нет доступа/BT-off не означают удаления. Удаление вне приложения тоже синхронизируется. Другие устройства, назначения кнопок/профили остаются.
