ИЗМЕНЕНИЯ
MainActivity: навигационные клавиши неигрового источника записываются в общий тест и передаются стандартной обработке Activity/Dialog; диагностический перехват не блокирует пульт. Игровые события по source/идентичности сохраняют прежний путь; счетчики M30 не меняются чужими клавишами.
FocusNavigation: отдельная белая рамка focus в foreground, не заменяет selected/live/disabled фон. Кнопки, кликабельные контейнеры, вкладки, профили и PadView доступны фокусу; подпись внутри профиля не создаёт вторую остановку. Стабильные ключи вкладок/профилей восстанавливают фокус после render. На TV стартовый фокус — текущая вкладка.
ConnectionGuide/MainActivity: до PAIR огоньки показывают режим включения; после PAIR постоянный огонёк — статус соединения. Справка объясняет пример X + START: два мигающих до пары, один постоянный после без смены X-input.
M30FirmwareActivity: та же рамка фокуса. M30FirmwareActivity/M30UpdateService — только номер приложения в отчётах; протокол и защитные проверки не менялись.
Bluetooth discovery/createBond не добавлены; пользователь предложил обсудить. Исследование — docs/BLUETOOTH-PAIRING-PROPOSAL-RU.txt; системное подтверждение может остаться, HID/появление InputDevice отдельно от pairing.

КОНТРОЛЬНЫЙ ПРОХОД НА TV
Обновить APK поверх прежнего. Стрелками перейти по трем вкладкам, в инструкции по четырем профилям; OK должен открывать выбранное, Back закрывать окно. Прокрутить вниз до «Дополнительно», открыть/закрыть диагностику пультом. В «Кнопки» стрелки должны отображать коды и одновременно менять фокус; кнопки M30 должны подсвечивать тест без случайного выбора меню. Экран прошивки можно открыть без запуска записи; не выполнять перепрошивку ради проверки навигации.
