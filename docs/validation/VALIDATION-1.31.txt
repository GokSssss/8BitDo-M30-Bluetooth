M30 Companion 1.31 — страницы джойстиков и общий тест клавиш

ПРОЙДЕНО
- assembleDebug, lintDebug, assembleDebugAndroidTest: BUILD SUCCESSFUL, lint без Error/Fatal. Инструментальные сценарии адаптированы и скомпилированы, но не запускались на устройстве/эмуляторе.
- Все 15 core-наборов пройдены. Новый InputTestStateTest проверяет независимость одинаковых клавиш с разных устройств, повторы без лишних нажатий, отпускание, оси/нейтраль, виртуальные источники, очистку удержания при отключении/потере фокуса, ограничение памяти и отсутствие изменений в ControllerBank.
- ButtonGuideTest дополнен наблюдаемым M30 HOME -> BUTTON_C 98: подсветка/отпускание HOME по исходному K:98, другие устройства не затронуты, необычная ручная HOME-привязка и код 98, уже занятый физической C, сохранены. Пользователь показал физическое сердечко с входящим BUTTON_C 98; сопоставление касается только схемы, не системного keycode.
- Для распознанного по имени M30 (8BitDo или VID 2DC8) после первого неназначенного кода 98 стандартная HOME K:110 заменяется локально на K:98 и сохраняется для descriptor+профиль. Клавиатуры/другие геймпады и назначения не на стандартный K:110 автоматически не меняются. При ручной калибровке автоматическая коррекция не выполняется.
- «Дополнительно»/прошивка и диагностика построены на страницах Джойстик 1/2, включая отключённый второй слот. Третья вкладка не строит PadView, Bluetooth/Choose/батарею, нижнюю схему действий или кнопки прошивки/дополнительно.
- На третьей вкладке — общий foreground-тест клавиатуры, пульта, геймпадов: источник/ID, keycode/имя, scanCode, source, down/up/repeat, удерживаемые клавиши, оси джойстика. События не назначают клавиатуру слоту M30 автоматически; счётчики контроллеров остаются раздельными. Для источника M30 показана отдельная серая панель 16 кнопок, для клавиатуры она скрыта.
- Системные события показываются только если Android доставил их Activity. BACK/громкость/прочие системные клавиши не перехватываются безусловно. Фонового/глобального мониторинга, новых разрешений и инъекции ввода нет.
- Вместо неинформативного «—» при неоднозначных имени/VID/PID показано «Режим не определён · ⓘ»; нажатие открывает реальные признаки и пояснение. Ручной профиль не выдаётся за измеренный режим. Определённый кандидат по-прежнему выбирается при открытии страницы; unknown не затирает ручной выбор.
- Побайтно с 1.30 совпали BootUpdateProtocol, M30Firmware, OfficialM30Files, UsbM30Link, BootModelProtocol, BootVersionProtocol, M30UpdateEngine, FirmwareUpdateResult, RadialGuideGeometry, ButtonGuideView. Механизм прошивки, проверки/пины официальных файлов и утверждённая нижняя схема сохранены.
