M30 Companion 1.28 — экспериментальное официальное обновление с Android

ПРОЙДЕНО
- assembleDebug, lintDebug, assembleDebugAndroidTest: BUILD SUCCESSFUL. Lint без ошибок; имеются некритические предупреждения о векторах, ресурсах и локализации.
- Все 13 core-наборов пройдены, включая M30FirmwareTest и BootUpdateTest.
- Строгий парсер DAT выполнен на повторно скачанном официальном HTTPS файле 2.01. Две секции, адреса, PID, версия и SHA-256 совпали. Несовпадение MD5 с каталогом сохранено как факт, не названо исправленным.
- Полные симуляции установки реальных официальных файлов 2.01 и 2.00: исходный payload 5006 передаётся полностью и без изменений; PID 0 не записывается. Проверены CRC16, порядок erase/write/version/readback/reset, другая модель, неизвестный SHA, запрет downgrade, прерывание на ошибке, неверный CRC/адрес/ACK и отсутствие reset при ошибке readback. Показатель 100% не выставляется самим движком до проверки USB-runtime вызывающим кодом.
- По официальной Windows DLL подтверждены выбор секции 5006, команды 5/4/3/2/7 и CRC16 запросов. Критические параметры сверены с дизассемблером. Запрос модели 8 ранее подтверждён физическим ответом пользователя; новых физических ответов в этой среде нет.
- В APK добавлены новый экран, системный выбор файла, ссылка на HTTPS 8BitDo, USB permission, явное подтверждение записи, single-device и model/version/file guards, foreground connectedDevice service, wake lock, проверка USB reconnect и отчёт.
- Разрешения INTERNET и POST_NOTIFICATIONS не добавлялись. Системное foreground-уведомление создаётся через startForeground; после reset не переобъявляется, когда USB permission старого устройства уже может исчезнуть. Приёмник USB permission имеет NOT_EXPORTED на API33+, совместимые flags на API26–32.
- Instrumentation дополнена проверкой firmware screen: установка выключена до верификации модели/версии/файла, открытие страницы не запускает update service. Только скомпилировано.
- aapt: app.m30.companion, versionName 1.28, versionCode 29. apksigner: подпись действительна, прежний сертификат e5141fbbfad5c2920cef4ee903e1c98a9e93727d206bc03b1ff919de702e9272.

МАТЕРИАЛЬНЫЕ ОГРАНИЧЕНИЯ
- На физическом телефоне/эмуляторе не запускалось. Новый read command 5, запись/стирание, service и reconnect на реальном M30 ещё не проверены. Это экспериментальный перенос, а не аппаратно подтверждённый обновлятор.
- Коды и собственная реализация изучены статически; программа Windows не выполнялась и USB-трасса не записывалась.
- Полного обратного чтения flash нет: ACK блоков, чтение поля версии и появление USB-runtime являются доступными подтверждениями, не побайтовым сравнением всей flash.
- Каталог MD5 расходится с фактическими официальными файлами, причина неизвестна. Допуск по SHA-256 относится к точно зафиксированным байтам с официального HTTPS сервера, не к цифровой подписи производителя. Это явно показано перед установкой.
- Старый BOOT 5750, другие модели/варианты M30 и произвольные/модифицированные DAT не поддерживаются. Настройка раскладки кнопок в прошивке не входит в эту работу.
