M30 Companion 1.32 — оценка D-input и диагностика батареи

ПРОЙДЕНО
- assembleDebug, lintDebug, assembleDebugAndroidTest: BUILD SUCCESSFUL. Lint без Error/Fatal. Инструментальные сценарии скомпилированы, не запускались на устройстве/эмуляторе.
- Все 16 core-наборов пройдены. ControllerTelemetryTest: заряд на дополнительном логическом источнике, приоритет основного источника и настоящего 0%, NaN/Infinity/вне диапазона/absent/virtual не превращаются в процент, известный вторичный VID/PID помогает общему источнику, противоречивые признаки остаются неизвестными.
- Новый совместимый кандидат ModeDetector: M30 с точным 2DC8:0651 → Android / D-input. Не применяется по одному имени/общему VID или к USB 5006; тип результата остаётся предположением по идентичности. DiagnosticsTest/ReconnectionTest адаптированы, пользовательское подтверждение режима не выдумывается.
- Источники телеметрии ограничены sourceIds текущего слота, проверяются ControllerBank и descriptor; другой подключённый контроллер/клавиатура не участвуют. Нет поиска батареи по похожему имени среди всех устройств и нет подстановки старых процентов.
- Чтение батареи 1.31 побайтно совпадало с сохранённым MainActivity до 1.27: проверялся только основной InputDevice через публичный BatteryState API 31+. В 1.32 добавлено чтение остальных логических источников того же контроллера, приоритет основного, исключения не ломают UI.
- В отчёте selected_controller_sources показаны ID/имя/VID/PID, battery_present, исходная capacity и battery_read_error. Ошибка чтения больше не теряется при диагностике. Нажатие на индикатор без процента открывает объяснение и инструкцию проверки Windows / X-input.
- Прошивочный протокол/движок/пины/результаты, физические привязки и утверждённая нижняя схема совпадают побайтно с 1.31. Меню и универсальный тест 1.31 сохранены.
- aapt: app.m30.companion, versionName 1.32, versionCode 33. apksigner: прежний сертификат e5141fbbfad5c2920cef4ee903e1c98a9e93727d206bc03b1ff919de702e9272.

ПОЛУЧЕННЫЕ ДАННЫЕ И ОГРАНИЧЕНИЯ
- Отчёт пользователя 1.31 на Android 16: M30 ID 8, 2DC8:0651, одна запись M30 среди available_input_sources, заряд «нет данных от Android». Другой источник A4 имеет иной VID/PID и не является основанием брать его батарею для M30.
- На прежних пользовательских скриншотах показывались Windows / X-input и 52%. Текущий отчёт подтверждает иную идентичность подключения, но не доказывает причину отсутствия BatteryState или ошибку прошивки. Смена режима могла произойти при включении/переподключении; повторная запись прошивки для правки приложения не нужна.
- Правило D-input подкреплено пользовательской идентичностью и публичным описанием M30 Start+B, 2DC8:0651: https://github.com/rommapp/ludo/issues/33 . Это совместимая эвристика, не официальное чтение регистра режима. Наблюдение X-input/заряда в другой среде: https://github.com/batocera-linux/batocera.linux/issues/10869 . Его выводы о Linux-драйвере не переносятся на Android как факт.
- Нет физического Android/M30 или эмулятора в среде. Восстановление процента батареи на телефоне НЕ подтверждено. Для текущего единственного источника без доступного заряда fallback не может создать данные; нужна проверка Windows/X-input и/или новый отчёт с подробностями BatteryState.
